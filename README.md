# Chapter 20

> A little interactive experience created for a very special 20th birthday.

**Chapter 20** is a personalized interactive birthday experience created as a gift for Shaymae's 20th birthday.

Rather than being just a traditional birthday page, the idea was to turn the gift into a small interactive journey, with surprises, playful interactions, multiple languages, and details made especially for her.

## What's Inside?

* A personalized birthday experience
* 20 candles to actually blow out
* Support for 5 languages
* Interactive elements designed to make the experience feel more like a small game
* Personalized birthday messages
* Animations and visual effects
* A few unexpected details along the way

## Built With

* HTML5
* CSS3
* JavaScript

## The Idea

The goal wasn't simply to make a beautiful birthday page.

It was to create something that feels personal, interactive, and unexpected — something to explore rather than simply read.

Every interaction was designed around one simple idea:

> A birthday gift should be something you experience, not just something you receive.

## Languages

The experience includes five language options, allowing the interface and birthday wishes to be experienced in different languages.

## The 20 Candles

One of the main interactive moments is the 20 candles.

Instead of simply displaying "Happy 20th Birthday", the idea was to make the birthday itself part of the interaction — she actually gets to put out all 20 candles.

## Why "Chapter 20"?

Because turning 20 feels less like a number and more like the beginning of a new chapter.

So this project became:

**Chapter 20 — a small beginning to a new chapter.**
